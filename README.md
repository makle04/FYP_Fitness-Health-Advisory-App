## Project Overview

FitSense AI is a full-stack personalised fitness and dietary advisory system built on unsupervised machine learning. The system clusters gym members into 14 distinct fitness archetypes using UMAP dimensionality reduction and HDBSCAN density-based clustering, trains a Random Forest classifier to serve real-time predictions through a Flask REST API, and delivers personalised workout and dietary recommendations through a React web frontend.

## How to Run

### Step 1 — Train the Model (Backend Pipeline)

Run the offline training pipeline from the project root. This loads the dataset, applies preprocessing, physiological pruning, feature engineering, UMAP dimensionality reduction, HDBSCAN clustering, and trains the Random Forest classifier:

```bash
python main.py
```

Expected terminal output:

```
INFO: Loading dataset
INFO: Pruned 270 unrealistic records
INFO: Dropped 0 rows during feature engineering
INFO: Searching best UMAP + HDBSCAN configuration
INFO: Selected parameters: UMAP neighbors=30, HDBSCAN min_cluster_size=25
INFO: Cluster summary: {'clusters': 14, 'noise_ratio': 0.16}
INFO: Saved results to project/data/output_with_activity_levels.csv
INFO: Training cluster prediction model
INFO: Cluster prediction model saved
```

This generates two files:
- `project/data/output_with_activity_levels.csv` — labelled dataset with cluster assignments and recommendations
- `project/models/cluster_model.pkl` — serialised Random Forest classifier

> **Note:** main.py must be run successfully before starting the API. The API depends on `cluster_model.pkl`.

---

### Step 2 — Start the Flask API

```bash
python api.py
```

The API will start on `http://localhost:5000`. You should see:

```
 * Running on http://127.0.0.1:5000
```

Test the API is running by visiting `http://localhost:5000` in your browser. You should see:

```
Fitness Health Advisory API Running
```

---

### Step 3 — Start the React Frontend

In a separate terminal, navigate to the `frontend/` directory:

```bash
cd fitness-frontend
npm start
```

The React app will open at `http://localhost:3000`.

> **Important:** Both the Flask API (port 5000) and the React frontend (port 3000) must be running simultaneously for the system to work end to end.

## API Reference

### POST /predict

Accepts a JSON payload containing nine user input attributes and returns a cluster assignment and personalised recommendation.

**Request Body:**

```json
{
  "Age": 28,
  "Weight_kg": 70,
  "Height_m": 1.75,
  "Session_Duration_hours": 1.5,
  "Calories_Burned": 600,
  "Max_BPM": 185,
  "Resting_BPM": 60,
  "Avg_BPM": 140,
  "Water_Intake_liters": 2.0
}
```

**Response:**

```json
{
  "cluster": 1,
  "recommendation": "High-intensity interval training with explosive movements and adequate recovery."
}
```

**Endpoint:** `POST http://localhost:5000/predict`  
**Content-Type:** `application/json`

## Machine Learning Pipeline Summary

| Stage | Description | Output |
|-------|-------------|--------|
| Preprocessing | Column standardisation, type coercion, missing value removal | Clean DataFrame |
| Physiological Pruning | Hard constraint filtering across 9 attributes + heart rate consistency rule | 1,261 valid records from 1,800 raw |
| Feature Engineering | BMI, Intensity, HRR, BPM Efficiency, Hydration Ratio | 8-feature input matrix |
| UMAP | Dimensionality reduction to 10 components (n_neighbors=30, random_state=42) | 10-dimensional embedding |
| HDBSCAN | Density-based clustering (min_cluster_size=25, min_samples=5) | 14 clusters, 16.0% noise ratio |
| Grid Search | 9 configurations evaluated, best selected by composite score | Score: 11.76 |
| Random Forest | 400 estimators, max_depth=10, min_samples_split=10 | 99.92% pipeline accuracy |

## Dataset

- **Source:** Publicly available synthetic gym members exercise tracking dataset (Kaggle)
- **Raw records:** 1,800
- **Features:** 15 attributes (demographic, physiological, activity, hydration)
- **Records after preprocessing:** 1,501
- **Records after noise exclusion:** 1,261 (used for classifier training)
- **No real personal health data was used — no ethics approval required**

---

## Known Limitations

- The system runs as a **localhost deployment only** — no production hosting is configured
- The Flask API and React frontend must both be running for end-to-end functionality
- The dietary module uses **deterministic formula-based computation** — not a learned model
- Meal plan templates are **static per goal category** — not individually personalised
- The Random Forest accuracy (99.92%) reflects **pipeline consistency**, not generalisation to unseen populations
- The dataset is **synthetic** — cluster structures may differ on real-world gym member data
